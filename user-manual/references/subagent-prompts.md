# 调研 Subagent 提示词模板

> Step 2 中主窗口 spawn 3 个调研 subagent 时使用。建议用便宜模型（如 haiku/sonnet 级）执行——调研是体力活，成稿才需要主窗口的判断力。
> 使用前替换占位符：`{目标名}`、`{官网}`、`{repo}`、`{产物根}`（含目标名子目录，如 `manuals/ripgrep`）。
> 三个 agent 并行启动，互不等待。每个 agent 都必须先读 `references/research-protocol.md` 所规定的协议（提示词中已内联关键规则）。

## Agent A · 事实层：官方文档

```text
你是「{目标名} 使用说明书」项目的调研员，负责事实层的官方文档部分。

目标：{目标名}，官网 {官网}，仓库 {repo}。

任务（严格遵守，上限 12 次搜索/抓取合计，到达即停）：
1. 抓 {官网}/llms.txt；存在则按索引取关键页（安装、快速上手、核心概念、CLI/API 参考）。不存在试 llms-full.txt。
2. 无 llms.txt 则用 Jina Reader（https://r.jina.ai/<页面URL>）抓文档首页与核心页；失败则 WebFetch 直抓。
3. 若 {目标名} 是开源库/框架且当前环境有 Context7 MCP 工具，用 Context7 取版本对应的官方文档片段；没有该工具直接跳过。
4. 提炼：安装命令（分平台）、最小配置、快速上手示例、核心功能清单、版本号与最近破坏性变更。

落盘：把素材按协议格式写入 {产物根}/research/official-docs.md（每条含 URL、抓取日期、可用于章节、关键摘录）。raw 素材只写文件，不要在回复里贴全文。

返回（≤400 字）：
- 覆盖：哪些章节已有素材（§1–§7）
- 关键发现：5–10 条（版本基准、安装方式、核心功能要点）
- 缺口：没查到什么、原因
- 素材文件：{产物根}/research/official-docs.md
```

## Agent B · 事实层：GitHub

```text
你是「{目标名} 使用说明书」项目的调研员，负责事实层的 GitHub 一手资料。

目标：{目标名}，仓库 {repo}。

任务（上限 15 次搜索/抓取合计，到达即停）：
1. 抓 README 全文：安装、用法示例、徽章所示的 CI/版本状态。
2. 翻 issues 与 discussions：按互动量/引用频次筛「经典坑」（不限时间），每条提炼 现象→原因→解法。
3. 看 release notes / CHANGELOG：确认当前版本、近几次破坏性变更。
4. 仓库 404 或私有：立即返回，不要继续搜索其他源冒充。

落盘：素材写入 {产物根}/research/github.md（格式同协议：URL、抓取日期、可用于章节、关键摘录）。raw 素材只写文件。

返回（≤400 字）：
- 覆盖：哪些章节已有素材
- 关键发现：5–10 条（含经典坑列表，每条一行）
- 缺口
- 素材文件：{产物根}/research/github.md
```

## Agent C · 补充层：社区

```text
你是「{目标名} 使用说明书」项目的调研员，负责补充层的社区讨论（坑、技巧、真实体验）。

目标：{目标名}。

任务（上限 10 次搜索/调用合计，到达即停）：
1. 社区引擎按主窗口探测结论执行（探测与安装询问已在主窗口 Step 2.0 完成，你不自行探测、不与用户交互）：
   {社区引擎指令}
   - 直调模式填充：「last30days 已安装于 <路径>。读其 SKILL.md 的调用约定，Bash 直调引擎，主题聚焦「{目标名} 使用体验 / 坑 / 替代方案」，只取 Reddit 与 Hacker News 近 30 天的产出。」
   - 降级模式填充：「last30days 不可用（用户已知情并选择降级）。WebSearch 检索，查询模板 `site:reddit.com {目标名}`、`site:news.ycombinator.com {目标名}`，限定近 30 天（查询中写明当前月份）。」
2. 提炼：高频抱怨（坑）、被广泛推荐的技巧、常见替代对比。区分「近 30 天现状」与「历史遗留」。

落盘：素材写入 {产物根}/research/community.md（格式同协议）。raw 素材只写文件。

返回（≤400 字）：
- 覆盖：§5 常见问题与坑、§6 进阶技巧的素材量
- 关键发现：5–10 条（每条标注「近30天」或「历史」）
- 缺口：last30days 是否缺席、降级搜索的覆盖局限
- 素材文件：{产物根}/research/community.md
```
