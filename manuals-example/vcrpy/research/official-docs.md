## 项目定位与工作原理（Rationale）
- URL: https://vcrpy.readthedocs.io/en/latest/
- 抓取日期: 2026-09-20
- 可用于章节: §1 简介与定位
- 关键摘录:
  - "This is a Python version of Ruby's VCR library."
  - "VCR.py simplifies and speeds up tests that make HTTP requests. The first time you run code that is inside a VCR.py context manager or decorated function, VCR.py records all HTTP interactions that take place through the libraries it supports and serializes and writes them to a flat file (in yaml format by default). This flat file is called a cassette."
  - 重放机制："When the relevant piece of code is executed again, VCR.py will read the serialized requests and responses from the aforementioned cassette file, and intercept any HTTP requests that it recognizes from the original test run and return the responses that corresponded to those requests."
  - 三大收益（原文要点）：The ability to work offline / Completely deterministic tests / Increased test execution speed.
  - 服务端 API 变更后的更新方式："all you need to do is delete your existing cassette files, and run your tests again. VCR.py will detect the absence of a cassette file and once again record all HTTP interactions."
  - pytest 生态：官方推荐 pytest-recording（https://github.com/kiwicom/pytest-recording）提供 fixtures。

## 最小可运行示例（quickstart）
- URL: https://vcrpy.readthedocs.io/en/latest/usage.html
- 抓取日期: 2026-09-20
- 可用于章节: §3 快速上手
- 关键摘录:
  - 上下文管理器形式（官方 synopsis）：
    ```python
    import vcr
    import urllib.request

    with vcr.use_cassette('fixtures/vcr_cassettes/synopsis.yaml'):
        response = urllib.request.urlopen('http://www.iana.org/domains/reserved').read()
        assert b'Example domains' in response
    ```
  - 装饰器形式：
    ```python
    @vcr.use_cassette('fixtures/vcr_cassettes/synopsis.yaml')
    def test_iana():
        response = urllib.request.urlopen('http://www.iana.org/domains/reserved').read()
        assert b'Example domains' in response
    ```
  - 官方对效果的表述："This test is now fast (no real HTTP requests are made anymore), deterministic ... and accurate (the response will contain the same headers and body you get from a real request)."
  - 装饰器可省略 cassette 路径：`@vcr.use_cassette()` —— cassette 以测试函数名命名、放在测试文件同目录（自动命名，详见进阶条目）。

## Record Modes（四种录制模式）
- URL: https://vcrpy.readthedocs.io/en/latest/usage.html
- 抓取日期: 2026-09-20
- 可用于章节: §4 核心功能
- 关键摘录（原文行为描述）:
  - `once`（默认）："Replay previously recorded interactions. Record new interactions if there is no cassette file. Cause an error to be raised for new requests if there is a cassette file." —— 有 cassette 时禁止任何新请求。
  - `new_episodes`："Record new interactions. Replay previously recorded interactions." —— 总是录制新交互（0.3.0 之前的默认行为）。
  - `none`："Replay previously recorded interactions. Cause an error to be raised for any new requests." —— 保证绝不发出真实 HTTP 请求，适合危险请求场景。
  - `all`："Record new interactions. Never replay previously recorded interactions." —— 强制重录 / 仅记录日志用。

## Unittest 与 Pytest 集成
- URL: https://vcrpy.readthedocs.io/en/latest/usage.html
- 抓取日期: 2026-09-20
- 可用于章节: §3 快速上手 / §4 核心功能
- 关键摘录:
  - `from vcr.unittest import VCRTestCase`：继承后自动录制/回放；cassette 经 `self.cassette` 暴露，如 `self.assertEqual(len(self.cassette), 1)`、`self.cassette.requests[0].uri`。
  - 默认路径规则："cassettes will be placed in the cassettes subdirectory next to the test, named according to the test class and method"，例：`cassettes/MyTestCase.test_something.yaml`。
  - 可覆写钩子：`_get_vcr_kwargs`、`_get_cassette_library_dir`、`_get_cassette_name`；要注册自定义 matcher 用 `_get_vcr` 钩子。
  - 自定义 setUp 必须调 `super().setUp()`，否则不生成 cassette。
  - 多重继承场景用 `from vcr.unittest import VCRMixin`。
  - Pytest：官方插件 pytest-vcr；另有 pytest-recording（额外提供网络访问阻断）。

## 敏感数据过滤（filter_headers 等）
- URL: https://vcrpy.readthedocs.io/en/latest/advanced.html
- 抓取日期: 2026-09-20
- 可用于章节: §4 核心功能
- 关键摘录:
  - 动机（原文）："If you are checking your cassettes into source control, and are using some form of authentication in your tests, you can filter out that information so it won't appear in your cassette files."
  - 三个入口：
    - `filter_headers=['authorization']`
    - `filter_query_parameters=['api_key']`
    - `filter_post_data_parameters=['api_key']`
  - 进阶：以上三项均接受 (key, value) 元组列表，value 可为——替换值 / `None`（删除该键，等同传纯字符串）/ 可调用对象（返回新值或 None）。例：`VCR(filter_headers=[('authorization', 'XXXXXX')])`；callable 签名为 `replace_auth(key, value, request)`。
  - 自定义请求过滤 `before_record_request`：回调返回 None 则该请求完全不录制；也可在回调内改写 request（示例：对 '/login' 路径剥离 query string）。
  - 自定义响应过滤 `before_record_response`：可改写响应体（示例：替换 body 中的用户名）或返回 None 跳过录制该交互。

## 其他高级选项（自动命名、回放控制、忽略请求等）
- URL: https://vcrpy.readthedocs.io/en/latest/advanced.html
- 抓取日期: 2026-09-20
- 可用于章节: §6 进阶技巧
- 关键摘录:
  - 自动命名：`@my_vcr.use_cassette` / `@my_vcr.use_cassette()` 均可省略路径；文件名=测试函数名，位置=cassette_library_dir 或测试文件同目录；加扩展名用 `VCR(path_transformer=VCR.ensure_suffix('.yaml'))`。
  - `decode_compressed_response=True`：录制前解压 gzip/deflate 响应体使 cassette 可读可编辑（解压发生在所有 before_record_response 之前；若被测库自身依赖解压行为则勿用）。
  - 忽略请求：`ignore_localhost=True`（忽略 localhost/127.0.0.1/0.0.0.0）、`ignore_hosts=[...]`；被忽略的请求"不录制、不回放，照常打到真实服务器"。
  - `cass.rewind()`：同一测试内回放完后倒带重放。
  - `allow_playback_repeats=True`：默认每个响应只能匹配回放一次；开启后同一响应可重复回放（配合循环调用）。
  - `record_on_exception=False`：默认即使测试出错也保存 cassette；设为 False 则只在成功时保存。
  - `drop_unused_requests=True`：保存时丢弃本次未用到的旧交互，防止 cassette 膨胀。
  - 扩展点：`register_serializer(name, obj)`（需实现 serialize(dict)->str / deserialize(str)->dict）、`register_matcher(name, fn)`（fn(r1, r2)，推荐用 assert 给出清晰报错）、`register_persister(cls)`（实现 load_cassette/save_cassette）、`custom_patches`（打补丁自定义 HTTPConnection）。

## 调试日志与 CannotOverwriteExistingCassetteException
- URL: https://vcrpy.readthedocs.io/en/latest/debugging.html
- 抓取日期: 2026-09-20
- 可用于章节: §5 常见问题与坑
- 关键摘录:
  - 打开日志：
    ```python
    import logging
    logging.basicConfig()
    vcr_log = logging.getLogger("vcr")
    vcr_log.setLevel(logging.INFO)
    ```
  - 日志可区分 "not in cassette, sending to real server"（录制）与 "Playing response for ... from cassette"（回放）；DEBUG 级别还能看到哪些 matcher 未匹配。
  - 典型报错：`CannotOverwriteExistingCassetteException: Can't overwrite existing cassette ('cassette.yaml') in your current record mode ('once'). No match for the request ... was found.` —— 报错信息会列出相似请求、成功的 matcher、失败的 matcher 及断言差异（示例中 query 参数 maxResults=200 vs 500），是排查"为什么没匹配上"的第一入口。

## 升级与迁移（0.x → 1.x cassette 格式）
- URL: https://vcrpy.readthedocs.io/en/latest/installation.html
- 抓取日期: 2026-09-20
- 可用于章节: §5 常见问题与坑 / §7 资源链接
- 关键摘录:
  - "The cassette format has changed in VCR.py 1.x, the VCR.py 0.x cassettes cannot be used with VCR.py 1.x."
  - 迁移脚本：`python3 -m vcr.migration PATH`（PATH 可为目录或单个 cassette；官方建议先备份）。
  - 最省事方案：删除旧 cassette 重新录制。
  - 自定义 serializer 在 1.0.x 需适配新 API：serialize 收 dict 返回 str；deserialize 收 str 返回 dict（不再是 requests/responses 对）。
