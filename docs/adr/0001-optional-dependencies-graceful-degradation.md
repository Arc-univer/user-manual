# 外部积木一律可选，优雅降级

user-manual skill 由多个外部项目拼装而成（社区调研引擎、文档抓取链、文档类 MCP）。决定：所有外部依赖均为**可选**——运行时探测，存在则调用其最优能力，缺失则降级到 Claude Code 内置工具链（WebSearch/WebFetch/Bash），skill 在任何裸环境下都可运行，绝不因缺依赖中止。理由：零必付依赖、零必配 API key，把使用摩擦降到最低；代价是每条链路都要写降级路径，且不同环境下素材质量有差异。

## Considered Options

- **硬依赖声明**（要求用户先安装各积木）：跟着上游更新最省事，但安装摩擦大，违背"拿来即用"。
- **vendor 引擎脚本进本 repo**：自包含，但需手动跟进上游更新，且把 Python 运行时变成硬要求。
